**必须先声明的三条折扣**（否则后面的结论会被高估）：

1. **语料是摘要 + 大模型生成的中文分析，不是全文。** 所有"某某声称提升 X 点"都只是摘要级证据；方法细节、消融、失败案例基本看不到。这一点在 B 桶尤其致命——奖励黑客类论文的结论极度依赖实验细节。
2. **RL 召回有约一半是噪声。** 1166 条标题里 644 条（55%）不含任何 RL 词汇（"reward / policy / rollout / RL / GRPO" 全无），579 篇日报评分 ≤ 6，两者高度重合。所以我不引用"篇数增长"当趋势证据，趋势一律按**月内出现率**（分母是核心集）算。
3. **中文分析本身有错。** 例：HISPO 那条摘要里 `policyoptimization` 缺空格；某条 id 为 `2508.06165` 的论文被标成 2026-09-24（时间穿越）。引用前建议核对原文。

**复现路径**：`extract_rl.py`（抽取）→ `bucket.py`（分桶）→ `slices/*.md`（精读材料）→ `rl_corpus.json` / `rl_titles.txt`。
