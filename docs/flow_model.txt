模型本体：token 序列 → 下一个 token 概率
============================

[输入]
  - E1: ids [B,T] / 词表查表 Embedding

[注意力]
  - A1: RMSNorm / （Pre-Norm，先归一化再进子层）
  - A2: 因果自注意力 + RoPE / [B,T,C]→[B,H,T,hd]（GQA 可省 KV）
  - R1: 残差相加 / x = x + attn(...)

[前馈]
  - F1: RMSNorm → SwiGLU 前馈 / 存知识的主力，参数占大头
  - R2: 残差相加 / x = x + ffn(...)

[输出]
  - O1: 最后 RMSNorm / + lm_head 线性层（分块算 loss）
  - O2: 只返回最后一步 logits [B,1,V] / 省掉 [B,T,V] 常驻张量

[边]
  E1 -> A1
  A1 -> A2
  A2 -> R1
  R1 -> F1
  F1 -> R2
  R2 -> O1
  O1 -> O2
  R1 -> F1   [重复 n_layers 次]

[注] 4 层就是把这套 block 堆 4 次；每层都有两条残差旁路，梯度才能回流到最底层。
