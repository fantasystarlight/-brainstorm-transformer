训练流水线：文本 → BPE → token 流 → batch
================================

[语料]
  - C1: ① 收集本地文本 / *.py / *.md（约 19 万字符）
  - C2: ② 先切 train/val / 再训 BPE（否则打分不诚实）

[分词]
  - B1: ③ 字节级 BPE / 反复合并最高频相邻对

[数据]
  - D1: ④ 编码成 token 流 / 存 uint16 的 .bin
  - D2: ⑤ 随机采样 batch / x = [t..t+T)  y = x 右移一位

[训练]
  - T1: ⑥ 前向 + 交叉熵 loss
  - T2: ⑦ 反向传播 → 梯度裁剪 → AdamW / warmup + 余弦衰减
  - T3: ⑧ 定期估 val loss / 只存最佳权重 ckpt.pt

[边]
  C1 -> C2   []
  C2 -> B1   []
  B1 -> D1   []
  D1 -> D2   []
  D2 -> T1   []
  T1 -> T2   []
  T2 -> T1   [每个 step 重复]
  T2 -> T3   [每 log_every 步]
  T3 -> T2   [继续训练]

[注] 关键顺序：BPE 只喂 train 文本 → val loss 才是诚实的「没见过」的困惑度。
