## 3. 十一个提案

每个提案给出：**主张 / 依据 / 机制 / 与已有工作的实质差异 / 最小可证伪实验 / 负对照与失败模式 / 判决标准**。
`新颖性` 是我自己的判断，分高/中/低，并说明理由——**低不代表不值得做，代表它更可能是工程胜利而非科学发现**。

---

### P1　给信用分配造一把尺子：`CreditBench` + 学习型信用分配器

**新颖性：高**（语料 1166 篇里，`shapley` 0 篇、对 oracle 信用的正确性检验 0 篇）

**主张**：在能把真实信用精确算出来的环境里，先把 6–8 种主流估计器对拍一遍，再决定要不要发明第 22 个 `*PO`。

**依据**：至少 12 篇论文声称改进了 token/step 信用（HISPO 2609.15471、GRAFT 2609.28963、Cliff 2609.02817、GMTS 2608.30632、TIAO、RLDS 2609.27035、SLCA-GRPO 2609.29050、CrEST 2608.13179…），没有一篇报告估计误差；PACT（2609.26355）给出了**公理化刻画**（完整性/前缀一致性/中性），但没有测任何估计器的偏差。

**机制**：
1. 构造真实信用可算的 MDP（我已在 `credit_oracle.py` 里做了 tabular 版本：K 步、每步 A 个动作、允许 TOL 次错误；用精确策略评估得到 `A(s,a)=Q−V`，随策略更新而更新，全程 float64）。
2. 同一批 rollout 上，让各估计器输出 per-(state, action) 信用，与 oracle 比对：Spearman 相关、符号正确率、MAE；再用该信用做 REINFORCE，比最终成功率（**信用归一化后再比，只让方向竞争**）。
3. 把"哪个估计器赢"当作环境结构的函数来报告，而不是当作方法的固有属性。

**已经跑出来的结果**（`credit_oracle.py`，CPU 约 36 秒，3 个种子，超参 `K=6, A=3, group=8, steps=300, lr=0.5`；数值取自 `credit_oracle_report.json`）：

| 区制（允许错误数） | oracle | 广播式（GRPO/RLOO） | MC 值差（GRAFT 类） | 首个错误（Cliff 类） | 只用位置 | 打乱（负对照） |
| --- | --- | --- | --- | --- | --- | --- |
| TOL=0 | 0.9900±0.0033 | **0.0052±0.0033** | 0.4154±0.2519 | 0.9870±0.0018 | 0.0000 | 0.0117±0.0105 |
| TOL=1 | 1.0000 | 0.9837±0.0024 | 0.9909±0.0060 | 0.9902±0.0027 | 0.0117±0.0166 | 0.0176±0.0235 |
| TOL=2 | 1.0000 | 0.9961±0.0016 | 0.9961±0.0016 | 0.9922±0.0016 | 0.1647±0.0578 | 0.0833±0.0542 |
| **与 oracle 的 Spearman**（TOL=0） | 1.0000 | **0.2431** | 0.2964 | **0.4687** | −0.1464 | −0.1457 |

（表中前三行是训练成功率；均匀策略的基线成功率分别是 0.0014 / 0.0178 / 0.1001，可由二项分布直接算出。）

读法（这三条是本提案的全部价值）：
- **估计器的排名随环境结构翻转**：不容错时广播式优势与真实信用相关性只有 0.24，且直接学不动（成功率 0.5%，与基线同量级），而"首个错误"启发式符号正确率 100%、几乎追平 oracle（0.987 vs 0.990）。容错时广播式又追平 oracle（0.984 / 0.996）。**任何"细粒度信用更好"的单点结论在这个二维表里都会被另一格推翻**——这正是要做尺子的理由。
- **MC 值差估计的方差是主要敌人**：TOL=0 时三个种子给出 0.232 / 0.772 / 0.242，均值 0.415、标准差 0.252。这印证了"critic 失败是实现问题而非范式问题"的说法，也说明**只报单次运行的结果不可信**。
- **负对照必须自带**：打乱信用后在三个区制里分别只有 0.012 / 0.018 / 0.083，与基线 0.0014 / 0.0178 / 0.1001 同量级（TOL=1 几乎完全重合，TOL=0 因样本极少而偏高于基线，三个种子为 0.025/0.010/0.000）。没有负对照的相关性数字没有意义。

**下一步（真正的科学问题）**：把该 oracle 环境扩到**多步算术链**（每步有可核验的中间结果），用 oracle 信用**监督一个小的信用预测头**（输入：token 熵、梯度范数、位置、隐状态；输出：标量信用），再看它在 GSM8K 上的 RLVR 里是否能取代启发式。这把"启发式→学习"从口号变成可测的回归问题。

**失败模式**：合成环境与真实推理不同构（外部效度）。缓解：至少要求结论在 3 个 K/A/TOL 组合上稳定，并在一个真实小任务（GSM8K + Qwen2.5-0.5B）上验证排序是否保持。

**判决标准**：若主流估计器与 oracle 的相关性普遍 < 0.3，则"细粒度信用"整条线需要重新解释为**尺度/归一化技巧**，而不是信用分配理论。

### P2　把"全对/全错"当作后验证据，而不是垃圾

**新颖性：中高**（把零方差与 Thompson sampling 结合已有 PAC 2608.30528；但"零方差=最大信息事件"的贝叶斯表述与悲观下界组合未见）

**主张**：零方差组不是训练事故，而是关于策略能力边界的**高信息量观测**。不要给它注入教师答案伪造信号，而要把它变成三件事的输入：预算分配、课程生成、保守更新。

**依据**：
- 处理零方差组的现有手段全是"外部补信号"：CGE 遮蔽最自信 token（2609.25773）、DEEPO 注入专家前缀（2609.28570）、ZPPO 把教师放进 prompt（2606.18216）、HCGRec 用 oracle hint（2608.11980）。ZPPO 自己指出注入教师会破坏 on-policy 假设。
- E 桶结论：off-policy 数据可补的差距约 3–5 pp（BOPTR 的迁移误差 3.41 pp，CI [2.32, 5.53]）——**外部信号能买到的上限是有限的**。
- A 桶精读的直接建议：这属于"分布外证据"，应改成保守更新，而不是伪造比较。

**机制**：
1. 维护每个 prompt 的能力后验 `p(正确)`（Beta-Binomial，用组内 k/n 更新）。零方差事件把后验推到 **0 或 1 的边界**——从 KL 意义上是单次观测里信息量最大的事件，也是**最该被用于决策**的地方。
2. 用后验做三个动作：
   - **预算分配**：Thompson sampling 在 prompt 之间分配 rollout（这部分与 PAC 重叠，不是创新点）；
   - **课程生成**：只在后验落在 [0.2, 0.8] 的能力边界带内**合成新题**（难度后验驱动，而不是静态难度标签——B/G 桶已证静态难度标签被证伪）；
   - **保守更新（创新点）**：对全错组，用离线 RL 的悲观原则，只对**已采样到的错误动作**做下界惩罚（`A ← min(A, −δ)`），绝不抬高未采样动作。惩罚强度随时间衰减，避免压死探索。
3. 关键对照：**"丢弃零方差组" vs "注入 hint" vs "悲观下界"**，三者用同一份算力。

**最小可证伪实验**：GSM8K + Qwen2.5-0.5B（本地可跑，全错组比例极高），group=8。指标不要只看最终准确率，要看**每 GPU-小时的有效梯度信息**（实测：batch 内 advantage 的方差、梯度信噪比）。三组：丢弃 / CGE 式遮蔽 / 悲观下界。

**负对照**：随机挑选要施加悲观惩罚的组 → 应无收益。若随机悲观也有收益，说明收益来自"降低了有效学习率/正则化"，本提案被证伪。

**判决标准**：悲观下界在**等算力**下优于丢弃 ≥ 2 pp，且优于 hint 注入（后者很可能初期更快但后期被 hack）。

### P3　`DriftAudit`：把训练-推理漂移变成一等观测量，一个量驱动三个旋钮

**新颖性：中高**（Score Centering 2609.20807 已给加性修正；BRACE 处理陈旧 critic；RTPO 处理异步漂移——但没人把它做成统一控制器）

**主张**：不要分别修 drift、调 clip、设 staleness 阈值。先**在线测量**漂移，再让同一个观测量去驱动信任域半径、重要性权重、以及更新门控。

**依据**：
- Score Centering（2609.20807）证明 TIM 下不稳定的主因是**随步累积的持续偏差 drift**，加性修正即可，且可与重要性采样复合；0.6B–30B 验证；"完全消除 TIM 不划算"是作者原话。
- Shadow Mask（2605.06850）：KV 压缩下采样器用稀疏上下文、学习器用稠密上下文，微小近似误差被 RL 放大，IS 校正方差大。
- BRACE（2609.09783）、RTPO（2608.18682）、T1 类工作各自处理异步/上下文/分词漂移，**没有共同度量**。
- E 桶缺口：staleness 的定量边界（过期步数 vs 崩溃点）缺失，现有只有行为实验。

**机制**：每步在线估计 per-token 漂移 `Δ_t = logπ_train(a_t|s_t) − logπ_infer(a_t|s_t)`（同 token id、同权重、不同引擎/精度/版本），以及累积漂移 `D = ‖EMA(Δ)‖`。然后：
1. `Δ` 做 score centering（已有工作）；
2. `D` 作为**信任域半径的自适应调节器**：漂移大 → 收紧 clip（这正是"静态 clip 在漂移下过松/过紧"的解药）；
3. per-token `Δ_t` 做**方差最优的重要性重加权**，而不是统一 clip；
4. `Δ_t` 超阈值的 token 直接**门控不更新**（这些 token 的梯度是噪声）。

**与已有工作的实质差异**：现有工作各修一个洞；这里把"漂移"从需要被消除的 bug 变成**驱动整个控制回路的观测量**，并且天然适用于单卡。

**最小可证伪实验（本地极度适合）**：RTX 4080 16 GB 上，vLLM 生成 + HF 训练天然存在 TIM。手动放大失配（bf16 训练 / fp16 生成；或对 KV 做不同程度量化），扫 5 个漂移档位，比三种方法：无修正 / 纯 IS / DriftAudit（= 测量 + 三旋钮）。模型 Qwen2.5-0.5B/1.5B，GSM8K。

**负对照**：把 `Δ` 打乱（shuffle）后做同样的修正 → 应退化为基线。**这是全篇最干净的一条负对照**，因为它检验的是"测量本身有用"而不是"修正项碰巧有效"。

**失败模式**：`Δ` 需要两套引擎各前向一次，成本翻倍。缓解：只在子集 token 上估计并测偏差；或利用已有的 forward 结果（很多框架本来就同时算 logprob）。

**判决标准**：漂移档位越大，DriftAudit 相对 IS 的优势越大（复现 Score Centering 的趋势并叠加 clip 调节的增益）。

### P4　奖励组合的在线投资组合 + `hack` 审计预算

**新颖性：高**（语料里 `materiality` 0 篇、`mechanism design` 0 篇；hacking 只有检测与门控，没有预算化）

**主张**：多奖励聚合的权重不应该由三个启发式信号决定（AMRP 2609.00213），而应该按"与留出金标的相关/风险"做**在线的投资组合优化**；同时给 reward hacking 维护一个**累计暴露量与阈值**，超限就触发降权/停用。

**依据**：
- AMRP 证明**聚合本身就是 hacking 源**：静态投影把性质不同的奖励剖面混成一个标量，偏向易学/密集的维度；它的对策是三个启发式信号（相对短缺、波动、近期进展），**没有最优性证明**。
- Rubric Dropout（2608.11669）量化了 hack 速度：训练判官分数持续上升、金标在 HealthBench-Hard 掉 3 分、ResearchQA 掉 22 分——**金标曲线是"判断是否在 hack"的可用观测量**。
- B 桶共识：冻结的 RM 必定被过度优化，需要用"真实结算流"（10% 金标）持续重拟合（类 Proof-Carrying Cognition 2609.09776）。AMRP 未测极端冲突的奖励维度。
- 长尾扫描：reward hacking 审计论文 8→9 月从 4 篇涨到 9 篇，但**基准互不可比**（DoM 在 Kimi K3 上升、GLM 5.2 下降），缺统一度量。

**机制**：
1. 把 K 个奖励/裁判当**资产**。权重 `w` 用在线镜像下降 / Exp3 更新：收益 = 该维度与**密封金标流**（held-out，只用于审计）的秩相关，风险 = 该维度方差 + 与 policy 的"共谋度"（该维度奖励与策略 logprob 的互信息）。
2. 每步做**审计抽样**：对一小部分轨迹用金标结算，得到重要性加权的"代理−金标"差距估计 `ĥ_t`。
3. 维护累计暴露 `H_t = Σ ĥ_t` 与其**置信上界**（用 e-process/SPRT 风格的序贯检验，B 桶建议过）。`H_t` 的置信上界超过 materiality 阈值 → 自动降权该维度 / 提高 rubric dropout 率 / 停用该维度。
4. rubric dropout 在这里从"一行修复"升级为**可调的控制变量**：hack 暴露越高，丢弃率越高。

**与已有工作的实质差异**：从"逐例检测 + 门控"升级为**有统计保证的抽检制度**，并首次给 hack 一个可比较、可预算的量（每单位训练算力允许的 hack 暴露）。

**最小可证伪实验**：构造一个"可 hack 但可验证"的玩具任务——评分器给"包含特定短语"的回答高分（可被刷），而金标是标准答案正确性。小模型 + GRPO，比：固定权重 / AMRP / 本提案。画三条曲线：训练代理分、金标分、累计 hack 暴露上界。

**负对照**：去掉金标审计流（只用代理分）→ hack 暴露上界应失效（曲线不再有预警能力）。
**失败模式**：审计集被间接优化（信息泄漏）→ 必须物理隔离并定期轮换。

### P5　激励相容的裁判：把严格 proper scoring rule 搬进 RL 的裁判训练目标

**新颖性：中**（B 桶显示"对数评分规则"已出现在**校准**研究里，如 ConRad 2608.25267 一带；但把裁判的**训练目标**改成严格 proper scoring 并加密封结算流，尚未见系统化）

**主张**：把 RLAIF 的裁判从"被优化的受害者"改造成"有激励约束的测量仪"——裁判不输出标量，而是输出候选集上的分布；其自身奖励用**严格 proper scoring rule** 对着密封的可验证子集结算。这样"迎合策略"不再是裁判的最优策略。

**依据**：
- Debate 训练（2608.17776）证明：裁判比策略弱时 hack 立刻发生，辩论能延缓但**削弱裁判反而加速 hack**，且需要额外辩论轮补偿——说明这是激励问题，不是容量问题。
- Bayesian Truth Serum 用于 sycophancy（2608.25267）说明"激励相容的提问设计"在这个领域已经开始被引入。
- B 桶把「用 10% 真实结算流重拟合 RM」列为共识，但那是**重训**，不是**改激励**。
- 语料里 `proper scoring rule` 只出现 1 次。

**机制**：裁判输出 `q ∈ Δ(候选集)`；裁判自身损失 = `−log q(真值)`（或 Brier），真值来自密封的可验证子集；策略的奖励 = `E_q[质量]`。理论上严格 proper scoring rule 的唯一最优策略是**报告真实信念**，因此裁判最优点与"取悦策略"解耦。可叠加辩论作为交叉验证。

**最小可证伪实验（便宜且现象明确）**：GSM8K 上小模型 + 小裁判，最终答案可验证。
- 组 A：标量裁判 + RLAIF；
- 组 B：本提案（分布裁判 + log score + 密封结算流）；
- 画"训练代理分 − 金标分"的发散曲线（Rubric Dropout 已证明这条曲线是 hack 的可用判据）。

**负对照**：把结算换成非严格 proper 的评分（如对 0/1 的 MSE）→ 应可被套利，发散曲线重现。
**失败模式（必须诚实）**：proper scoring 只保证"报告真实信念"，**不保证信念本身接近真理**。裁判系统性偏差不会被修好——这一条要在论文里写清楚。

### P6　把档案馆搬进 LLM RL：MAP-Elites 式的覆盖率目标

**新颖性：中高**（QD 在 LLM 对齐里只有 MoDA 2609.14896 用"角色条件"做软多样性，`map-elites` 0 篇；语料中 QD 相关仅 2 篇）

**主张**：不要再用"熵正则 + λ 系数"这种隐式手段管理多样性。显式定义行为描述子、维护档案馆、把**覆盖率**当一等训练目标。

**依据**：
- ES vs GRPO（2608.27351）：ES 有**更广的推理覆盖**，Pass@1 提升的同时 Pass@k 更高，而 GRPO 出现熵坍缩；并提出 GRPO→ES 顺序训练（说明覆盖与锐化是可以分别优化的）。
- BOPTR（2609.01274）：RL 的收益大部分是"内部化的搜索"——即把基础模型可达但少采样的轨迹变成默认行为。**这与覆盖率直接相关，且给出了可度量的兑换率。**
- MoDA（2609.14896）：质量门控 + 角色条件多样性奖励让 SBERT 多样性 +265% 且 pass@1 提升 7–10.3%——证明多样性与质量不是必然权衡。
- C 桶最大空白：探索预算在 group size × 分叉深度 × 温度 × prompt 选择上的**联合最优分配无理论**。

**机制**：
1. 行为描述子（BD）候选：推理长度分位、使用的策略标签（枚举/代入/构造/画图）、工具调用次数、中间步骤数、答案格式。**先做 BD 消融**——BD 若与能力无关，整个方法退化。
2. 维护 grid archive：每个 cell 保留该 cell 内质量最高的解答；rollout 采样时按 **cell 空缺度/稀疏度**加权（MAP-Elites 的标准做法）。
3. 奖励 = 质量门控（必须过阈值）+ λ·新颖度（到同 cell 其他解的距离）。
4. 把 group-relative 的"组"从"同一 prompt 的多次采样"改成 **archive-relative**：对比对象是档案馆里的精英而非本次采样的同伴。这对 GRPO 的方差结构是实质性改动。

**度量**：`QD-score`（各 cell 最优质量之和）、`coverage`（非空 cell 比例）、`pass@1`、`pass@k`、`unique-solution rate`、策略熵的纵向曲线。

**最小可证伪实验**：GSM8K/MATH 子集 + Qwen2.5-0.5B/1.5B，3 个种子（这一步就超过了 97% 的核心集论文），比 GRPO / MoDA 式角色条件 / 档案馆式。

**负对照**：随机 cell 采样（去掉新颖度项）→ coverage 增益应消失。若仍有增益，说明增益来自"更多采样"而不是覆盖率机制。

### P7　可核查性预算：只在对可验证的地方把信用变稠密（**判决实验优先**）

**新颖性：高**（A 桶精读把它列为"最有价值缺口 #1"：局部性/密集性/教师信息三因素从未被同一实验分离）

**主张**：过程奖励的收益来自哪里，是可以被一个 2×2 实验判决的。我的预测是：**收益来自"可核查性"，而不是"密集性"或"位置正确性"**——在无法被外部核验的位置给稠密奖励，应该无效甚至有害。

**依据**：
- 反证已经存在：仅用终局奖励也能 +10 点（A 桶 #35）；用 rollout 的 (a,o') 做辅助世界建模也能提分（PaW 2606.02388）——说明"稠密"本身可能不是关键。
- 正面证据：符号反传（PLVR 2608.28421）、现实结算奖励（Proof-Carrying Cognition 2609.09776）——**能被外部核销的奖励**才带来可靠增益。
- Cliff（2609.02817）、GRAFT（2609.28963）、TRCA 全是启发式位置选择，且都没报告自身噪声量级。

**机制**：对每条轨迹定义**可核查 token 集 V**（算式结果、检索事实、代码断言、工具参数撞库、单元测试覆盖的片段）。信用 = 结果信用 + 仅在 V 上的过程信用；核查次数受预算 B 约束（每轨迹最多 b 次检查，b 由 bandit 按边际收益分配）。给出设计原则：**信用密度 ≈ 可核查性**，而不是"越密越好"。

**判决实验（2×2，这是全篇最该先做的一个）**：

|  | 在真实 V 上加稠密奖励 | 在随机位置加同量稠密奖励 |
| --- | --- | --- |
| 稠密奖励总量 = D | A 组 | B 组 |
| 稠密奖励总量 = 0（纯终局） | C 组 | — |

- 若 **A ≈ B > C**：收益来自**密集性**，与可核查性无关 → 本提案被证伪（这同样是好结果：整条线可以简化）。
- 若 **A > B ≈ C**：收益来自**可核查性** → 过程奖励的设计原则应当改写。
- 若 **A > C > B**：随机稠密奖励有害，文献里大量启发式位置选择正在制造这种伤害。

**可行性**：合成数学任务（每个中间步骤可执行核验），CPU 或单卡数小时；不需要大模型。

**负对照**：同量随机稠密奖励（B 组本身就是负对照，且必须给"同量"以满足 F 桶指出的有效学习率对齐要求）。

### P8　训练 ↔ 推理的算力兑换率调度器

**新颖性：高**（BOPTR 只做行为拟合与预测，没人把它当调度器用）

**主张**：RL 与推理时搜索是同一笔预算的两种支出。用实测的边际收益曲线（而不是直觉）在 `{RL 步数, rollout 宽度/深度, 推理时搜索}` 三者间做等边际分配；并且**每次 RL 改进都必须报告 coverage（新可达）与 sharpening（重加权）的分解**。

**依据**：BOPTR（2609.01274）给出 `N_Base ≈ α·N_RL^β`，跨 10 模型迁移误差 3.28–4.87 pp、未见过的基准 5.03 pp——**RL 的增益有相当一部分是"把基础模型已经能到达的操作点变成默认行为"**，即 sharpening。这类增益在推理时用 best-of-n 同样买得到，所以必须做联合预算分配。

**机制**：
1. 在线估计两条边际曲线：单位 RL 算力 → pass@k 增益；单位推理搜索算力 → pass@k 增益。
2. 等边际原则分配总预算；曲线随训练漂移，需要在线重估（这是个连续控制问题，不是一个静态配方）。
3. 每 N 步做一次 **gain decomposition**：用 Base checkpoint + 预算搜索去逼近 RL checkpoint 的 pass@k 曲线，残差即"真正的能力增量"。

**最小可证伪实验（本地可做）**：MATH/GSM8K 子集 + 0.5B/1.5B，等总算力下比三种配置：(a) 全部给 RL；(b) 全部给 best-of-n；(c) 等边际混合。指标：pass@1、pass@k、以及"能力增量"残差。

**负对照**：把预算平均分配（等分）→ 应劣于等边际分配。若等分不差，说明算力分配不是瓶颈。

### P9　把 rollout 当对照实验来设计：最小化的是**梯度方差**，不是奖励方差

**新颖性：中高**（`Luck Is Not Skill` 2609.24144 已给出关键反例；`statistical power` 在语料中出现 0 次）

**主张**：组大小、是否配对、温度种子复用，应该由"最小化策略梯度估计的迹"来解，而不是由"让奖励对比更干净"来决定。

**依据**：Luck Is Not Skill（2609.24144）用**预注册 + 3 seed** 的协议发现：配对 rollout 能降低奖励对比的方差，**但不必降低梯度方差**；对单侧评分噪声它甚至给出"奖励对比改善而梯度方差上升"的反例。工具故障下最终成功率 +5.1 pp（三个种子全为正），但**预注册的学习曲线判据没有通过**。

**机制**：用实验设计语言重写 rollout 组织：
- prompt = 区组（block）；环境噪声 = nuisance factor；
- **共同随机数（CRN）**用在策略采样种子与可控环境事件上；
- 目标函数不是奖励对比的方差，而是 `tr(Cov(ĝ))`；
- 输出一个**计算器**：给定噪声结构（工具故障率、评分翻转率）与预算，算出最优的 `prompt 数 × group size × 是否配对`。

**最小可证伪实验**：本地小模型 + 可控噪声注入（工具故障 / 评分翻转两档 × 三个种子），直接测梯度协方差迹（Luck Is Not Skill 的 probe 做法）与学习曲线，比较我们的分配公式 vs 常用默认（group=8、不配对）。

**负对照**：无噪声时配对不应有增益。若仍有效，说明机制不是方差。

### P10　RL 的持续学习：按能力分区的正交更新

**新颖性：中高**（GCPO 2608.11674 做全局硬投影；`EWC` 0 篇；Continual RLVR 2608.18574 只做诊断与 prompt replay）

**主张**：多域 RL 的遗忘与能力挤出，可以用**按能力分区的、可预算的**梯度投影来治，而不是全局硬投影（GCPO 自认可能限制探索）。

**依据**：
- GCPO：主子空间重叠的**瞬态尖峰先于性能退化**；硬双侧正交投影能消除 excursion，并在数学/代码/工具三类任务上超过 GRPO/DAPO/GSPO，同时**消除响应长度膨胀、稳定策略熵**。
- Beyond Forgetting（2608.18574）：持续 RLVR 存在共享推理能力的流失。
- ES vs GRPO（2608.27351）：ES 的参数漂移大但**功能稀疏**——大参数移动不等于广泛功能改变；这暗示"功能子空间"是可分的。
- Refusal 的几何（2609.06934）：post-hoc 安全 Δ 近正交于能力方向——能力方向确实存在可分离结构。

**机制**：为每个能力/奖励维度维护一个低秩梯度子空间（在线 PCA / EMA）。把更新分解到 (a) 目标方向、(b) 与已学能力的共享方向、(c) 正交噪声方向；对 (a) 全步长、(b) 保守步长、(c) 投影衰减。给出**能力正交预算**：允许多少共享方向的更新量。这是 PCGrad/OGD 思路在 LLM RL 上的分区版本。

**最小可证伪实验**：小模型两阶段连续 RL（数学 → 代码），测阶段 2 的提升与阶段 1 的保留率；对比 无投影 / GCPO 全局硬投影 / 分区投影。

**负对照**：打乱子空间归属 → 应退化到无投影水平。若打乱后仍有效，说明收益来自别的东西（例如整体缩小有效学习率）。

### P11　用世界模型做反事实过程奖励，并对它做"核销"

**新颖性：中高**（PaW 2606.02388 用 rollout 学世界模型但只作辅助损失；FLARE 2609.23808 用生成式奖励模型但可被 hack；`simulator collapse` 2608.12253 已给出警告）

**主张**：过程奖励不必来自人类的 rubric 或学出来的评委——可以来自**反事实**：保持前缀，用动作条件的世界模型采样"若换个动作会怎样"，从而得到有环境依据的过程信号；再用**少量真实核销**校准世界模型的偏差。

**依据**：
- PaW 证明 on-policy rollout 里的 `(a, o')` 对的辅助建模能稳定提分；
- FLARE 的全生命周期密集监督证明过程信号价值巨大，但 GRM 自身可被 hack（B 桶独立指出"生成式奖励是当前最值得追踪的两条线之一"）；
- One Frozen Simulator Is Not Enough（2608.12253）：单一模拟器会坍缩，策略过拟合其主导模式——所以世界模型必须带不确定性惩罚与漂移预算。

**机制**：
1. 训练 `W(o'|s,a)` 的集成（ensemble）；
2. 对失败轨迹在关键节点做反事实重采样，得到"若做 X 则后续可解"的证据 → 过程奖励；
3. **模型利用（model exploitation）的防线**：ensemble 分歧作不确定性惩罚 + 与现实环境的 KL 预算 + **定期用真实环境核销**（花少量真实 rollout 检验 W 的预测，用偏差修正奖励）。

**最小可证伪实验**：合成可执行任务（有真值的环境），扫"核销比例 0% / 1% / 10%"。**预测**：核销比例 0 时会出现典型的 model exploitation 曲线（代理奖励上升、真值下降）；核销比例升高后消失。

**负对照**：用打乱的动作-观测配对训练 W → 反事实奖励应退化为噪声。
