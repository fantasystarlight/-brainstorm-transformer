判决实验决策树：从提案到「继续 / 转下一个」
=======================

[选点]
  - S: 从首批提案中选一个

[前置检验]
  - Q1: 有可运行的负对照？
  - FIX: 先补负对照再跑

[执行]
  - Q2: 等算力 & ≥3 种子？
  - RUN: 跑实验，记录判决判据

[判决]
  - Q3: A ≈ B > C ？
  - Q4: A > B ≈ C ？
  - Q5: A > C > B ？

[行动]
  - V1: 证伪：收益来自密集性 / 不是可核查性
  - V2: 成立：改写过程奖励 / 设计原则
  - V3: 文献里的启发式位置 / 正在制造伤害
  - V4: 无显著差异 → / 加种子/加算力再判
  - NEXT: 记录入库，转下一个提案

[边]
  S -> Q1
  Q1 -> FIX   [否]
  Q1 -> Q2   [是]
  FIX -> Q2
  Q2 -> RUN   [是]
  RUN -> Q3
  Q3 -> V1   [是]
  Q3 -> Q4   [否]
  Q4 -> V2   [是]
  Q4 -> Q5   [否]
  Q5 -> V3   [是]
  Q5 -> V4   [否]
  V1 -> NEXT
  V2 -> NEXT
  V3 -> NEXT
  V4 -> NEXT

[注] 本树以 P7 的 2×2 判决实验为例；换成 P1/P3 时只替换 Q3–Q5 的分支标签。
