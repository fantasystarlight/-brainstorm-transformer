## 附录 C　知识点表（图谱的文字版）

下面 52 个知识点就是这张图谱的全部节点，按 8 个知识域分节。`用于`一列是哪个提案依赖它；每个知识点的**关系**（基于 / 对立 / 迁移）画在 `docs/kg_knowledge_a|b|c.png` 里。
定义都是**一句话、可判真伪**的写法，不是名词解释。

### C.1 优化目标与信任域（`K-OPT`，7 个）

| 知识点 | 一句话 | 用于 |
| --- | --- | --- |
| 策略梯度定理 | ∇J = E[∇logπ(a\|s)·A(s,a)]：只有优势（而不是回报本身）进入梯度，这是所有信用分配争论的起点 | P1 P9 P10 |
| 重要性采样比 | ρ=π_new/π_old，它让旧数据可用，但也让梯度方差随 ρ 爆炸——P3 的第三个旋钮就是它 | P3 P9 |
| 信任域与 KL 约束 | 用 KL/比率约束限制单步策略移动；"精确信任域"自带 stabilizer 与熵控制项，而启发式 clip 不自带 | P3 P8 |
| clip 死区 | 硬 clip 在比率出界处给零梯度，等价于控制论的执行器饱和：误差持续累积而反馈断开，于是策略在动量下开环漂移 | P3 |
| 熵正则与熵预算 | 熵项既是探索来源也是收敛温度；把熵系数当作可测量的预算，才谈得上"局部降、全局不塌" | P2 P6 |
| 反向 KL 与模式覆盖 | 反向 KL 倾向覆盖多模式（mode-covering），前向 KL 倾向坍缩到单峰——"熵该涨该降"的争论本质是在选哪个方向 | P6 |
| 镜像下降 / Bregman 散度 | 把 KL 正则的 PPO/GRPO/BPO 统一成镜像下降的不同散度选择，是判断"新目标 vs 换散度"的判据 | P1 |

### C.2 信用分配（`K-CREDIT`，7 个）

| 知识点 | 一句话 | 用于 |
| --- | --- | --- |
| 优势函数 A=Q−V | 信用分配的数学定义本身；"token 级信用"至今没有公认定义，直到 PACT 给出公理刻画 | P1 |
| 广义优势估计 GAE | 用 λ 在偏差与方差之间插值；PACT 证明中间步骤的 critic 误差可以与被估计的信用同量级 | P1 P9 |
| 组相对基线（RLOO/GRPO） | 同 prompt 多次采样的均值构成可信的状态价值估计——这是 GRPO 有效的真正原因，而不是"组归一化"这个形式 | P1 P2 P6 |
| 信用分配三公理 | 完整性 + 前缀一致性 + 中性唯一确定 token 级信用；可用来判定任何新方法的信用是否自洽 | P1 |
| 过程奖励与不可验证性 | 过程奖励的收益可以来自局部性、密集性、或教师信息三者之一，三者从未被同一实验分离 | P7 |
| 轨迹图与图上 Bellman 反传 | 把多条轨迹接成图、在图上做 Bellman 迭代，是"少采样也能拿到 step 级信用"的主要技术路线 | P1 P9 |
| 偏差-方差权衡 | 细粒度不等于更好：粒度越细，单位信号的方差越大；实测中 MC 值差估计的三个种子横跨 0.23~0.77 | P1 P9 |

### C.3 奖励与验证（`K-REWARD`，8 个）

| 知识点 | 一句话 | 用于 |
| --- | --- | --- |
| 可验证奖励 RLVR | 奖励来自可执行/可核验的判定，而不是学出来的评委——这是目前信噪比最高的奖励来源 | P4 P7 |
| 奖励塑形与有界饱和 | 好的塑形应"有界 + 先快增后饱和"；无界塑形会让策略把分数刷到无穷 | P4 |
| Rubric-as-Reward | 用 LLM 依评分细则打分；它同时是当前的主流解法**和**新的可优化漏洞 | P4 P5 |
| 奖励黑客 | 策略优化的是代理奖励与真实目标的差，而不是真实目标；判据是"训练评委分数上升而金标分数下降" | P4 P5 |
| 多奖励聚合与投影 | 静态加权把性质不同的奖励剖面压成一个标量，偏向易学维度——**聚合动作本身**就能诱发黑客 | P4 |
| 生成式奖励模型 GRM | 用生成式模型输出结构化奖励信号，比标量判别器 richer，但同样可被过度优化 | P11 |
| 校准与密封结算流 | 留出一小部分真实结算数据，只用于审计/重拟合奖励模型；"密封"是为了防止策略间接优化审计集 | P4 P5 |
| 严格 proper scoring rule | 让裁判报告分布并按对数评分结算，则"说真话"是占优策略——把裁判从受害者变成激励相容的测量仪 | P5 |

### C.4 探索与覆盖（`K-EXPLORE`，6 个）

| 知识点 | 一句话 | 用于 |
| --- | --- | --- |
| 组内奖励方差与零梯度组 | 组内奖励全同（全对或全错）时优势归零、梯度消失；这是 GRPO 族的结构性盲区 | P2 P6 P7 |
| 熵坍缩 | 策略熵单调下降导致 pass@k 崩、输出同质化；但"正确轨迹熵降得更快"，所以须区分局部下降与全局塌陷 | P6 |
| pass@k 与覆盖率 | 覆盖率（能到达的解集大小）与准确率（默认行为有多好）是两个可分别优化的量，必须分别报告 | P6 P8 |
| 质量-多样性 QD / MAP-Elites | 显式维护"行为描述子 → 最优解"的档案馆，把覆盖率当一等目标，而不是靠熵系数隐式管理 | P6 |
| Thompson 采样与信息增益 | 按"后验方差的期望下降"而不是奖励方差来分配下一次采样——零方差组在贝叶斯视角下信息量最大 | P2 P8 |
| 难度后验与课程 | 静态难度标签已被证伪；能力边界（可解率 0.2~0.8 带）应由在线后验估计并驱动出题 | P2 |

### C.5 系统与漂移（`K-SYS`，6 个）

| 知识点 | 一句话 | 用于 |
| --- | --- | --- |
| 训练-推理失配 TIM 与 drift | 采样引擎与训练引擎的微小差异会随训练步累积成持续偏差；完全消除 TIM 不划算，但它可以被测量并加性抵消 | P3 P8 |
| 离策略校正与重要性重加权 | 用 ρ 修正旧数据；在 drift 面前统一 clip 次优，逐 token 的方差最优重加权更好 | P3 |
| staleness 与异步 | 异步 rollout 让不同轨迹来自不同策略版本；容忍边界目前只有行为实验，没有定量曲线 | P3 |
| 显存墙与 KV 压缩 | 长上下文 rollout 的 KV 占用是硬约束；压缩会引入"采样用稀疏上下文、训练用稠密上下文"的 off-policy 偏差 | P3 P8 |
| rollout 吞吐与长尾调度 | 长尾轨迹拖垮 makespan，rollout 与训练阶段的资源配比是独立的优化变量 | P8 |
| 蒸馏-然后-RL 的顺序性 | 先蒸馏后 RL 稳定优于联合优化；联合会让两个信号互相干扰——这是"顺序即架构"的证据 | P8 |

### C.6 理论与诊断（`K-THEORY`，5 个）

| 知识点 | 一句话 | 用于 |
| --- | --- | --- |
| 收敛率与策略改进下界 | 把策略改进分析推广到新的"时间参数化"（如信息密度时间）才能给出下界；目前多数目标是定性的 | P3 |
| 损失景观（自旋玻璃映射） | 表格设定下 RLVR 的景观是良性的、无局部极小；真实障碍是扩散势垒与梯度估计误差——"景观不崎岖 ≠ 翻得过去" | P1 |
| 主子空间几何与正交投影 | 每次更新与预训练权重主子空间的重叠出现瞬态尖峰时，性能即将退化；把更新投影到互补子空间可构造性避免 | P10 |
| 参数漂移 ≠ 功能变化 | ES 的大幅参数移动只对应稀疏的功能改变；所以"更新幅度"不能当作学习进度的度量 | P10 |
| 机制可解释性与 SAE | 用固定特征的稀疏自编码器追踪 RL 前后的表征漂移；实测 RL 增益约 80% 可由少数"格式脚手架"特征解释 | P4 |

### C.7 方法论（`K-METHOD`，5 个）

| 知识点 | 一句话 | 用于 |
| --- | --- | --- |
| 预注册与判决判据 | 先写下判据再跑，否则等于没有判据；一个反例是配对 rollout 通过了成功率判据、却没通过预注册的学习曲线判据 | 全部 |
| 负对照与鉴别力 | 每个实验都要有"必须失败"的对照，且对照要能真的失败（我给的测试里，故意写错的 DP 必须被断言抓出来） | 全部 |
| 等算力对比 | 只有 2/277 篇对齐了算力；不对齐算力时，绝大多数"新算法收益"无法与有效学习率/batch/熵预算的重调区分 | 全部 |
| 多种子与配对随机数 | 只有 9/277 篇报种子；共用随机数可以把环境噪声从对比里消掉，但**不保证**梯度方差下降 | P9 |
| 可监控性曲线 | 只报 pass@1 会漏掉"分数涨、可监控性跌"：实测 RL 后 CoT 可监控性可掉约 30 点，熵/长度/pass@k 三条曲线应一起报 | 全部 |

### C.8 跨域迁移源（`K-XFER`，8 个）

| 知识点 | 一句话 | 迁移到 |
| --- | --- | --- |
| 离线 RL 悲观价值（CQL/IQL） | 对分布外动作取价值下界；零方差组正是"分布外"的证据，应保守更新而不是伪造比较 | P2 |
| 最优停止与运筹调度 | 把"信用单元在哪里结束"写成停时问题，把"何时插入训练/重算教师"写成抢占式调度 | P1 P8 |
| 因果推断双重稳健估计 | 用 g-formula/TMLE 同时纠正奖励模型偏差与轨迹选择偏差，把"自信的幻觉"当混杂而不是靠硬门控砍掉 | P1 P7 |
| 差分隐私与噪声会计 | 噪声既是隐私机制也是正则；用会计规则严格记账"累计 hack 暴露"，而不是逐例检测 | P4 |
| 审计抽样与 materiality | 把奖励黑客从"逐例检测"升级为有统计保证的抽检制度，并给一个可比较的暴露预算 | P4 |
| 机制设计与拍卖（VCG） | 让诚实报告成为占优策略；把 rubric 各项当竞标者按边际贡献支付，可抑制评分共谋 | P5 |
| 持续学习正交梯度（PCGrad/OGD） | 把梯度投影到与旧任务正交的子空间以防遗忘；按能力分区后比全局硬投影更少限制探索 | P10 |
| 排队论与物化视图 | 把教师输出当物化视图、用 drift 累积当 staleness 代价，决定"重算还是复用" | P8 |
