因果自注意力：掩码与 KV cache
===================

[投影]
  - Q1: 两个投影：q 出 n_heads 份 / kv 只出 n_kv_heads 份（GQA）
  - Q2: 拆头 + GQA 共享 / [B,T,C] → [B,H,T,hd]

[位置]
  - P1: 施加 RoPE / （只旋转 q/k，不碰 v）
  - P2: 有 KV cache？ / 把历史 k/v 接在前面（存 n_kv_heads 头）

[打分]
  - S1: 因果掩码 / 未来位置 = False（不可见）
  - S2: SDPA 一步算完 / softmax·V（不物化 T×T 矩阵）

[输出]
  - V1: 权重 @ v / 历史信息被加权搬进当前位置
  - V2: 多头拼回 + 输出投影 / 把 **未展开** 的 k/v 存回 cache

[边]
  Q1 -> Q2
  Q2 -> P1
  P1 -> P2
  P2 -> S1
  S1 -> S2
  S2 -> V1
  V1 -> V2
  Q2 -> P1   [Tq=1 且 cache 命中时复用历史]

[注] 训练时缓存不参与（每个位置并行算）；生成时每步只算 1 个 token，靠 cache 复用历史 k/v。
