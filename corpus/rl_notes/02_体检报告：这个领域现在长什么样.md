## 1. 体检报告：这个领域现在长什么样

### 1.1 命名饱和：18 个 `*PO`，其中 17 个是新变体

核心集标题里能数出 **18 个以 `PO` 结尾的方法名**（含 GRPO 本身），即 17 个新变体：
SAPO / HISPO / PlanPO / GCPO / RTPO / MileGPO / TIGPO / PGPO / DEEPO / SRPO / TTPO / VERPO / GUPO / GVPO / TEMPO / PEA-DPO / SLCA-GRPO。
把它们的差别摊开看，绝大多数落在两个轴上：

- **粒度**：token → segment → turn → subtask → 子问题；
- **重加权**：熵选 token、梯度幅度选 token、长度条件化、饱和重加权、不确定度加权。

真正换了优化对象的不多：`Bellman Policy Optimization`（2609.15987）把 Bellman 方程直接当目标，`ConSPO`（2605.12969）把 GRPO 改写成判别式/InfoNCE 形式，`ANO`（2605.02320）把 clip 换成 C∞ 增益场，`PaW`（2606.02388）在 RL 里顺带学世界模型。

### 1.2 证据质量：这是一个"改进≈超参重调"的重灾区

| 指标 | 277 篇核心论文中的数量 |
| --- | --- |
| 摘要里提到随机种子 / 多次运行 | **9 篇**（3.2%） |
| 摘要里明确"同算力/同预算"对比 | **2 篇**（0.7%） |
| 提到 GPU-小时或墙钟总成本 | 极少，且多为单步加速比 |

只有 2 篇提同预算。而 F 桶精读给出的独立佐证非常一致：ZPPO 的"平均正确率 < 0.5 判难题"、GMTS 的"只训 top-20% 高熵 token"、TIAO/JPO 的 token 重加权、QUATRO 的显式信任域，**全都等价于在改有效学习率 / 有效 batch / 熵预算**，却全都**没有做把这三者对齐的控制实验**。

> 结论：核心集里大量"比 GRPO 高 X 点"的结论，目前**无法与超参重调、噪声、以及评测集选择区分开**。这不是耸人听闻，是 275/277 篇共同留下的空白。

两条可读的信号：
- "堆 agent 架构"不再是加分项（agentic 份额 28.0% → 22.3%），**训练动力学与奖励可靠性**才是新战场；
- **对 RL 本身的审计在升温**（reward hacking 检测、机制可解释性、RL 实验的元研究如 `PoEM` 2609.30226）。这个方向目前引用量低、竞争少。

### 1.4 已经沉淀下来、可以当事实用的三条

1. **响应级 group 均值是可靠的 state-value 代理**（GRAFT 2609.28963 的原话；GRPO 在单轮任务上的成功就源于它忠于 advantage 的定义）。
2. **轨迹级标量优势对"多技能组合"任务是有损的**——SLCA-GRPO（2609.29050）的跨段污染、RLDS（2609.27035）的子任务异质性诊断、RTPO（2608.18682）的 turn 级崩坏，指向同一件事。
3. **前缀/分词/上下文一致性是一等公民，不是工程细节**：重分词、turn 边界漂移、上下文截断会直接毁掉 advantage 与样本的对应关系（Agent Lightning 2608.17528 系列、RTPO）。

### 1.5 四组没有解决的冲突（这才是金矿）

| 冲突 | 一方 | 另一方 |
| --- | --- | --- |
| **critic 该不该有** | BPCO 每 prompt 只采 1 次就追平 group 基线 | "critic 不划算"是主流默认；SP³O 说 critic 失败是实现问题（value flattening） |
| **细粒度信用是否真有用** | HISPO 说段级优于 token/序列级 | PACT 证明 RLOO 的粗粒度信号在**期望梯度**上与 token 级信用一致；RLDS 自认两个基准上无显著增益 |
| **熵该涨还是该降** | 正确轨迹熵下降更快（ERR+） | 熵坍缩↔大 k pass@k 下降，须保高熵（弱模型引导、QKL 输入侧正则） |
| **过程奖励的收益从哪来** | 局部性（首个错误）、密集性（每步都给）、教师信息（特权解）三者混在一起 | 有反证：仅用终局奖励也能 +10 点；rollout 的 (a, o') 做辅助任务也能提分 |

**这四组冲突的共同根因是同一件事：没有尺子。** 没人能在"真实信用已知"的环境里检验自己的估计器，于是所有争论都停留在"我的基准上我更高"。
